= pyvcp-gtk(1)

== NAME

pyvcp-gtk - PyVCP panels drawn with GTK

== SYNOPSIS

*pyvcp-gtk* [*-g* _WxH+X+Y_] [*-c* _component-name_] [*-x* _XID_ | *--xid*] _myfile.xml_

== DESCRIPTION

*pyvcp-gtk* reads a PyVCP panel file and shows it with GTK 3 instead of
Tk. The widgets are the GladeVCP HAL widgets (LED, meter, bar, dial,
jog wheel, buttons, scales, spin buttons).

The panel creates the same HAL pins as *pyvcp*(1), with the same names,
types and automatic numbering, so *pyvcp-gtk* can replace *pyvcp* in a
HAL file without other changes.

Tk-only options in the panel file, such as _relief_, _cursor_ or
_padx_, are ignored. _text_, _font_, _fg_/_foreground_,
_bg_/_background_, _width_ and _anchor_ are applied. Other unsupported
options print one warning each.

== OPTIONS

*-g* _WxH+X+Y_::
  This sets the initial geometry of the window.
  Use 'WxH' for just size, '+X+Y' for just position, or 'WxH+X+Y' for both.
  Size / position use pixel units. Position is referenced from top left.
*-c* _component-name_::
  Use _component-name_ as the HAL component name.
  If the component name is not specified, the basename of the XML file is used.
*-x* _XID_::
  Embed the panel in the existing X window _XID_ instead of opening a
  window, as *gladevcp* does. Use it with `EMBED_TAB_COMMAND` and `{XID}`
  in AXIS, GMOCCAPY or Gscreen.
*--xid*::
  Put the panel in a plug and print the plug's X window id on stdout.

== EXAMPLE

In a HAL file:

----
loadusr -Wn mypanel pyvcp-gtk -c mypanel mypanel.xml
----

As a tab in AXIS or GMOCCAPY, in the INI file:

----
[DISPLAY]
EMBED_TAB_NAME = Panel
EMBED_TAB_COMMAND = pyvcp-gtk -c mypanel -x {XID} mypanel.xml
----
